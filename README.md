## 🚀 Featured Projects

### 🥋 ShinKai: Karate Club App
A mobile companion app for members of a Shinkempo karate club. Track training, RSVP to events, study techniques per belt and measure progress with built-in strength tests.

- 📅 Event calendar with RSVPs, reminders and geofenced attendance logging
- 🗺️ Mapbox map with live position and turn-by-turn navigation
- 💪 Punch force (accelerometer) and kiai volume (microphone) tests
- 🔔 Live push notifications over a LavinMQ (AMQP) broker
- 🏗️ MVVM with Jetpack Compose, Hilt, Room and Retrofit

[Repository](https://github.com/MriceDK/Shinkai-Karate-App) · [Download the APK](https://appdistribution.firebase.dev/i/b0d43bfb2c9e44fe)

### 🥗 Adria: NutriScan
A full-stack food-scanning and nutrition platform built for a simulated 2084 "Return to Earth" startup course. Users scan food, track body stats and health analyses, and order supplements.

- 🔌 .NET 8 REST API with Swagger covering scans, food composition, users, analyses, supplements and orders
- 🖥️ Vue 3 + Vite single-page app with scanner, shop, statistics and tracker views
- 🔔 Push notification subscriptions
- 🐳 Dockerized MySQL for local dev, multi-stage Docker build served by Nginx, GitLab CI

[Server](https://github.com/MriceDK/Adria-server) · [Client](https://github.com/MriceDK/Adria-Client) · [Test environment](https://github.com/MriceDK/Adria-Test-Environment)

### 🎬 HowestPrime Movies Platform
An event-driven cinema platform made of a staff backoffice, a movie microservice, a ticketing microservice, and Docker and Terraform infrastructure for local testing and Azure deployment. Built for the **Build and Deploy** course at Howest.

[View the full project](https://github.com/HowestPrime-Movies-Project)

### 🦭 Seal: Custom Version Control System
A custom version control system written from scratch in Rust, built to learn how tools like Git work under the hood.

- 🦀 Written in Rust
- 🚧 Work in progress, repository coming soon
